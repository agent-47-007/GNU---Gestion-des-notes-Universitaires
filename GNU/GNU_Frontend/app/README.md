# GNU App

Espace réservé à l'application mobile GNU.

L'application partagera avec le web :

- l'identité visuelle GNU ;
- les rôles `ETUDIANT`, `ENSEIGNANT` et `AGENT` ;
- les contrats de l'API `/api/v1` ;
- les règles LMD et les statuts de notes.

Aucune technologie mobile n'est imposée dans cette première étape. Le projet pourra être initialisé en Flutter ou React Native après validation de ce choix.
