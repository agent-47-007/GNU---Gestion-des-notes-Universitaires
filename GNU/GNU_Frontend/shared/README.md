# GNU Shared

Conventions communes aux clients web et mobile :

- Encre `#1B2942`
- Papier `#DEDACB`
- Papier clair `#F1EEE2`
- Rouge-encre `#8C2F2F`
- Or-sceau `#A9762C`
- Ardoise `#5B5F66`

Typographies : Fraunces pour les titres, IBM Plex Sans pour l'interface et IBM Plex Mono pour les données académiques.

API backend : `http://127.0.0.1:8000/api/v1` en développement.
